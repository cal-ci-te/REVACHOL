# 自定义组件开发路线图

> 本文档记录 REVACHOL 自定义交互组件的规划方向。所有组件遵循配置驱动、状态可追踪、与用户物品系统联动的设计原则。

---

## 现有组件

| 组件 | 功能 | 交互方式 | 配置维度 |
|------|------|----------|----------|
| 贴纸系统 | 静态装饰层叠加 | 拖拽、缩放、切换样式 | 位置、大小、图片、固定/绝对定位 |
| 拼图组件 | 滑动拼图解锁 | 滑块、鼠标拖动 | 图片源、块数、溢出、移动端禁用 |
| 魔法箱子 | 开箱动画、物品抽取 | 点击、弹窗 | 物品池、弹出动画、冷却时间、自定义贴图 |
| 健康监控 | 后端状态指示 | 轮询、事件驱动 | 轮询间隔、超时、重试次数、广播行为 |

---

## 计划中的组件方向

### 1. 状态门组件（State Gate）

- **描述**：用户持有特定物品时解锁隐藏内容
- **交互方式**：物品条件检查 → 显示/隐藏区块
- **配置示例**：
  ```json
  {
    "requiredItem": "silver_key",
    "display": "hidden_content",
    "fallback": "locked_message"
  }
